# Abstract

Radio Frequency Fingerprint Identification (RFFI) provides a complementary physical-layer authentication mechanism for Automatic Meter Reading (AMR) gateways by exploiting hardware-inherent transceiver imperfections. In open-set deployments, gateways calibrate an acceptance threshold $\tau$ using borrowed proxy transmitters and then report false acceptance rates measured on held-out packets from those same radios. We identify a fundamental flaw in this practice — **The Familiar Stranger Problem**: because the threshold was tuned against these proxy devices, they are no longer true strangers, and the reported security is artificially optimistic.

Our most striking finding concerns **proxy-count sensitivity**. Evaluating across 20 seeded episodes on the 60-device LoRa RFFI benchmark (26,000 packets, 292 complex baseband features, strictly frozen threshold), we show that **single-proxy calibration ($k=1$) creates a dangerous $+19.41\%$ blind spot**: familiar testing reports $\text{FAR}_A = 2.67\%$, but true physical strangers penetrate at $\text{FAR}_B = 22.08\%$. This distortion stabilizes only at $k \ge 5$ proxy devices. To isolate the familiarity effect from device-composition differences, we introduce a **device-matched paired design** evaluating identical devices on identical packets under familiar ($\tau_{\text{full}}$) versus unfamiliar ($\tau_{(-j)}$) calibration, revealing a modest but statistically significant gap of $\Delta\text{FAR}_{\text{matched}} = +1.47\%$ ($95\%$ device-level bootstrap CI: $[+0.72\%, +2.40\%]$).

A key negative result concerns the cost of mitigation: an identity-robust threshold ($\tau_{\text{robust}}$) reduces true-stranger penetration from $11.55\%$ to $4.17\%$, but the False Rejection Rate surges from $8.49\%$ to $30.18\%$ — rejecting nearly 1 in 3 legitimate meter packets, which is operationally unacceptable for battery-powered AMR networks. Per-device vulnerability is severely heterogeneous ($0.0\%$ to $98.5\%$), with 7 of the 8 hardest rogues clustering in a single hardware block, though device-aggregated Spearman correlation between feature distance and vulnerability is not statistically significant ($\rho = 0.21$, $p = 0.11$, $n = 58$). While closed-set classification achieves $99.43\%$ macro-$F_1$, the open-set AUROC of $0.949$ with $\text{FAR}_B = 11.55\%$ and $\text{FRR} = 8.49\%$ confirms that RFFI serves as a defense-in-depth screening layer, not a standalone security gate. These findings establish that physical-layer authentication must be evaluated under identity-disjoint protocols with $\ge 5$ diverse proxy devices to avoid dangerously overestimating real-world protection.
