# Abstract

Radio Frequency Fingerprint Identification (RFFI) provides a complementary physical-layer authentication mechanism for Advanced Metering Infrastructure (AMI) and Automatic Meter Reading (AMR) gateways by exploiting hardware-inherent transceiver imperfections. In open-set deployments, gateways must reject rogue transmissions from unregistered devices. To calibrate the operational acceptance threshold ($\tau$), standard engineering practice frequently evaluates false acceptance on held-out packets from a set of borrowed, unfamiliar transmitters (proxy-unknowns). In this paper, we identify and rigorously evaluate **The Familiar Stranger Problem**: because the gateway threshold is calibrated against these proxy devices, they become *familiar strangers*; testing on additional packets from the same physical devices yields an artificially optimistic False Acceptance Rate (FAR).

Evaluating across 20 seeded experimental episodes on the 60-device benchmark LoRa RFFI dataset (26,000 packets) using a 292-dimensional complex baseband feature set under a strictly frozen threshold, we show that random device allocation yields an episode-level familiarity difference of $\Delta\text{FAR} = +0.56\%$ ($95\%$ CI: $[-1.55\%, +2.39\%]$, positive in $65\%$ of episodes), which is masked by extreme physical device heterogeneity (per-device false acceptance varies widely from $0.0\%$ to $98.5\%$). To eliminate device-composition confounding, we introduce a **device-matched paired evaluation** that measures the exact same physical devices on identical test packets when treated as familiar ($\tau_{\text{full}}$) versus unfamiliar ($\tau_{(-j)}$); this protocol isolates the familiarity effect, uncovering a statistically significant gap of $\Delta\text{FAR}_{\text{matched}} = +1.47\%$ ($95\%$ device-level bootstrap CI: $[+0.72\%, +2.40\%]$). 

A sweep over proxy count $k \in \{0, 1, 3, 5, 10, 15\}$ demonstrates that single-proxy calibration ($k=1$) induces an acute $+19.41\%$ optimism gap ($\text{FAR}_A = 2.67\%$ vs. $\text{FAR}_B = 22.08\%$), stabilizing at $k \ge 5$. Furthermore, we evaluate an identity-robust threshold ($\tau_{\text{robust}}$), which lowers true-stranger penetration from $11.55\%$ to $4.17\%$, but imposes a severe operational false rejection penalty (mean FRR surges from $8.49\%$ to $30.18\%$). While closed-set meter classification achieves $99.43\%$ macro-$F_1$, open-set AUROC remains at $\approx 0.949$, demonstrating that RFFI serves as a defense-in-depth screening layer rather than a standalone perimeter gate. These findings establish that AMR physical-layer security must be evaluated under identity-disjoint protocols to avoid overestimating real-world protection.
