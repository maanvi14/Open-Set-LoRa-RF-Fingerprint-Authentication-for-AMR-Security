# Abstract

Radio Frequency Fingerprint Identification (RFFI) provides a complementary physical-layer authentication mechanism for Advanced Metering Infrastructure (AMI) and Automatic Meter Reading (AMR) gateways by exploiting hardware-inherent transceiver imperfections. In open-set deployment, gateways must reject rogue transmissions from unregistered devices. To calibrate the acceptance threshold ($\tau$), standard engineering practice frequently evaluates false acceptance on held-out packets from a set of borrowed unfamiliar transmitters (proxy-unknowns). In this paper, we identify and measure **The Familiar Stranger Problem**: because the gateway threshold is calibrated against these proxy devices, they become *familiar strangers*; testing on additional packets from the same physical devices yields an artificially optimistic False Acceptance Rate (FAR). 

Evaluating across 20 seeded experimental episodes on the 60-device benchmark LoRa RFFI dataset (26,000 packets) under a strictly frozen threshold, we show that true stranger false acceptance ($\text{FAR}_B = 21.28\% \pm 8.01\%$) significantly exceeds familiar stranger false acceptance ($\text{FAR}_A = 17.05\% \pm 8.31\%$), creating a statistically significant **Familiarity Gap** of $\Delta\text{FAR} = +4.22\%$ ($p = 0.0215$, Wilcoxon signed-rank test; positive in 70\% of episodes, peaking at $+17.00\%$), while False Rejection Rate ($\text{FRR} = 25.88\%$) remains identical by construction. A sweep over proxy count $k \in \{0, 1, 3, 5, 10, 15\}$ reveals that calibrating without proxy devices ($k=0$) permits a catastrophic $63.00\%$ true-stranger penetration, while single-proxy calibration ($k=1$) induces an acute $+18.89\%$ familiarity gap. To mitigate this vulnerability, we evaluate a **Leave-One-Proxy-Out (LOPO)** calibration remedy: LOPO reduces true-stranger estimation bias from $-0.0422$ to $-0.0281$. These findings demonstrate that AMR physical-layer security guarantees must be validated under strictly identity-disjoint protocols.
